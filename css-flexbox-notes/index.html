Align Self

Align self property ka use karte hai ye batane ke liye ki kisi specific content ya box ko container ke andar alag se align karna hai. ye property kisi specific content ya box ko container ke start, end, center, stretch me align kar sakta hai. ye property align-items ki tarh hi hota hai lekin align-items se hum sare content ya box ko ek sath align karte hai lekin align-self se hum kisi specific content ya box ko alag se align kar sakte hai.

Ye hamesha sdheedi hi line mai hota hai flex direction e according kadhi ya leti disha mai.

Iski property vo sari hoti hai jo align-items ki hoti hai jaise flex-end flex-start center stretch ye sirf unbox ko jisko aap alg dikhna chate ho iske liye aap sab box per ek jaise class dekar usko style kar lenge or jis box ko alg dikhna hai ek or special class de denge phir us class ko alag se align-self property ka use karke end center aur start mai kar sakte hai.
