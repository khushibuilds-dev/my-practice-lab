Why I Built This Lab? 🤔

When I was building projects on freeCodeCamp, my mind kept racing with ideas: "Can I use this property differently? Can I also build this layout on my own?" Mera dimaag chal raha tha ki kya yeh sab sach mein alag se ho sakta hai? So, I didn't stop at tutorials. I created this separate repository "my-practice" to experiment live. Yahan par koi tutorial ka copied code nahi hai—these are my own real experiments and layouts!
