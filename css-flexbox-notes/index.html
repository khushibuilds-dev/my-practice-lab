My personal flexbox notes

We use first display: flex; than use many propertise

flex-direction, justify-content, align-items and other properties.

Flex-direction

1 Property- flex-direction: row;

flex-direction property ka use karna padta hai ye batne ke liye ki contnet ki tarh chiye row chiye ya cloumn chiye row defalut hoti to agr row chaiye to kuch mat karo ye pahele se hai

2 Property- flex-direction: column;

Is property se hum content ko cloumn(vertical "khadi line") mai kar sakte hai.

Property- justify-content: flex-start

Is property ka use karne se kuch nahi hota hai ye default hi property set karta hai

Property- justify-content: flex-end

Iss property ke use se chheze agar row mai hai to row mai column mai hai to column mai hi last mai chaili jati hai
